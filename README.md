#💰 M-Chama Management System

A modern, secure, and scalable web-based platform designed to manage chamas (investment groups) efficiently. This system digitizes contributions, loans, meetings, and member management with a professional and user-friendly interface.

🚀 Features

👥 Member Management

Register and manage chama members

Assign roles (Admin, Treasurer, Member)

Track member activity and contributions

💵 Contributions Tracking

Record daily, weekly, or monthly contributions

Automatic balance calculations

Contribution history per member

💳 Loan Management

Request and approve loans

Interest calculation

Track repayments and outstanding balances

📊 Financial Reports

Generate reports for contributions and loans

Export data for record keeping

Real-time financial insights

📅 Meetings & Events

Schedule meetings

Notify members

Record meeting minutes

🔐 Authentication & Security

Secure login system

Role-based access control

Data protection and validation

🛠️ Tech Stack

Frontend

HTML5

CSS3 (Modern UI + Animations)

JavaScript (Vanilla / React optional)

Backend

Node.js / Django / C++ (depending on implementation)

Database

MongoDB / MySQL / PostgreSQL

📦 Installation & Setup

1. Clone the Repository

git clone https://github.com/HenleyKaranja/mchama-connect.git
cd mchama-system

2. Install Dependencies

npm install

3. Run the Application

npm start

4. Open in Browser

http://localhost:3000
